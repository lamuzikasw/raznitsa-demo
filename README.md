# Разница — public demo

Интерактивная демонстрация интерфейса для сопоставления букмекерских событий и prediction markets. Главный экран показывает радар возможностей, барьер 1.000, экономику после расходов и ручную лесенку выбора события.

## Что находится в репозитории

- статический HTML/CSS/JavaScript;
- вымышленные локальные данные;
- демонстрационный радар с тремя заранее связанными парами;
- демонстрационная лесенка выбора события;
- демонстрационный расчёт распределения капитала с пошаговой формулой доходности;
- пересчёт курса, расходов, защитного запаса и доступного демо-объёма;
- локальный список наблюдения, который хранится только в браузере;
- официальные логотипы Winline и Polymarket.

В публичной версии нет API-ключей, запросов к фидам и стаканам, production-коннекторов и алгоритма автоматического сопоставления. Все названия команд, коэффициенты, цены и объёмы являются демонстрационными. Для типографики браузер загружает публичные Google Fonts.

## Запуск локально

```bash
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173/`.

## Что намеренно не опубликовано

- URL и адаптеры реальных фидов;
- получение стаканов и валютного курса;
- production-логика сопоставления событий;
- ключи, токены, cookies и пользовательские данные.
