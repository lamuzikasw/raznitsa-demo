# Разница — public demo

Интерактивная демонстрация интерфейса для сопоставления букмекерских событий и prediction markets.

## Что находится в репозитории

- статический HTML/CSS/JavaScript;
- вымышленные локальные данные;
- демонстрационная лесенка выбора события;
- демонстрационный расчёт распределения капитала.

В публичной версии нет API-ключей, сетевых запросов, production-коннекторов и алгоритма автоматического сопоставления. Все названия команд, коэффициенты, цены и объёмы являются демонстрационными.

## Запуск локально

```bash
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173/`.
